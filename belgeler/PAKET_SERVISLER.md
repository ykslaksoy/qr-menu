# Paket servisler bölümü

## Amaç
Anlaşılabilecek paket / yemek kanallarını listeler.
**Anlaşılanlar** üstte ve **tikli**; diğerlerinde tik yok, altta.

## Dosya
`config/paket-servisler.json` → `anlasildi: true | false`

## Arayüz
`/paket-servisler`

## Not
Tik şu an anlaşma durumu işaretidir; siparişlerin panele düşmesi için API entegrasyonu ayrı iştir (sonra).
