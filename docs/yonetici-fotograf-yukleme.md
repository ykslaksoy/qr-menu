# İşletme fotoğrafları (stok yerine gerçek görsel)

1. Panele girin → **Menü** → ürün satırında **Görsel** alanına dokunun.
2. **Kendi fotoğrafım** ile telefondan veya bilgisayardan JPEG/PNG seçin (büyük dokunma alanı).
3. Kaydedildiğinde `gorselKaynak: yukleme` olarak işaretlenir; stok katalog görsellerinin yerine geçer.

Kapak ve logo için **Ayarlar → Marka** bölümündeki yükleme alanlarını kullanın.
